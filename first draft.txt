39. Delay & Reminders
Set a hard "delay until" date on any task

Auto-arms up to 3 reminders: T-2 days, T-1 day, T-0

Every 45 s background check

Fires browser notification + toast

Bell badge on task row shows pending count

Clearing the delay removes all reminders

Works exactly for cases like "ثبت نام مربیگری شطرنج" — set the deadline, get reminded.

40. XP & Leveling
XP per task based on estimate + dopamine type

Dislike = 2× base

So-so = 1.3× base

Love = 1× base

Level = floor(sqrt(XP / 25)) + 1

Progress bar in Today view
